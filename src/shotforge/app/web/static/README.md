# ShotForge Web Static Assets

This directory is the Web UI foundation layer.

- `design-system.css` keeps reusable tokens, layout primitives, icon button styles, and motion utilities.
- `shotforge-ui.js` is for shared UI behavior that is not tied to one form or one page.
- Feature-specific scripts should stay close to the template until they become reusable.
- Future icons, images, animation presets, and component styles should live under this static tree instead of being scattered through templates.
